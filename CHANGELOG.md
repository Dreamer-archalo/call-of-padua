# Changelog

## Alpha 0.2.0 — AFTERMATH (2026-10-12)
- Reworked Piazza delle Erbe blockout with procedural Gothic arcade, vaulted roof, street markets, debris, cars, lamps, and barricades.
- Added mission stages: hostile patrol > field transmitter interaction > escape under reinforcements.
- Added interaction via keyboard E, standard gamepad Square, and a dedicated mobile button.
- Redrew rifle and pistol separately, improved HUD and waypoint indicators.
- Added procedural sound feedback, startup damage grace period and touch-first shooting correction.
- Tested desktop and mobile interactions and simulated Gamepad API with Playwright.

## Alpha 0.1.0 — INITIAL PROTOTYPE
- Single-sector first-person sandbox, two weapons, elementary hostile AI, minimap, optional third-person camera and basic touch/controller inputs.
